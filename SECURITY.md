# Reporting a security concern

Please do not post credentials, personal documents, exploit details, or other sensitive
information in a public issue. If private vulnerability reporting is enabled for this
repository, use **Security → Advisories → Report a vulnerability** on GitHub. Otherwise,
email the maintainer privately at [engmaryamameen@gmail.com](mailto:engmaryamameen@gmail.com).

Include the affected revision, the impact you observed, and minimal reproduction steps
using synthetic data. Do not test against other people's accounts or documents. Do not
include access tokens, passwords, real résumés, or job applications in your report.

The project is maintained on a best-effort basis; there is no guaranteed response or fix
time. See [security and privacy](docs/security-and-privacy.md) and the
[threat model](docs/threat-model.md) for the intended boundaries and known limitations.
